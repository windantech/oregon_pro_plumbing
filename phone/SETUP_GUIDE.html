Oregon Pro Plumbing
Browser Phone

Install a secure calling portal for administrators and technicians. One US business number, computer calling, and optional Kenyan-mobile forwarding.

1. Install the portal

  1. Open hosting File Manager and navigate to public_html.
  2. Create a folder named phone.
  3. Upload Oregon_Pro_Plumbing_Browser_Phone.zip to that folder and extract its contents directly inside it.
  4. Open https://oregonproplumbing.com/phone/setup.php.
  5. Create your administrator login and use SQLite if available, or create a MySQL database via cPanel and choose MySQL.
  6. After successful installation, delete setup.php in File Manager.
  7. Sign in at https://oregonproplumbing.com/phone/login.php.
Do not upload into the plumbing website's existing files. Keep this separate in /phone/, and don't overwrite your current booking, Stripe or SMTP files.

2. Get your Twilio credentials

Open Twilio Console. Under your account's API Key & Token section, create a Standard API Key. Copy the Key SID (SK...) and secret once. Obtain the Account SID (AC...) and Auth Token securely from the Console.

Under Twilio Voice, create a new TwiML Application and set:

SettingValue
Friendly nameOregon Pro Plumbing Browser Phone
Voice Request URLhttps://oregonproplumbing.com/phone/api/outgoing.php
HTTP methodPOST

Copy the new App SID (AP...). In the browser phone's Settings, paste all five values and save.

Never put Auth Token or API Key Secret in HTML, JavaScript, email or WhatsApp. Enter them only through your portal's secure Settings page.

3. Upload the browser calling library

  1. Visit Twilio's official Voice JavaScript SDK releases.
  2. Download a current stable version 2.x release and extract it on your computer.
  3. Find dist/twilio.min.js in the downloaded archive.
  4. Open your browser phone's Settings → Twilio Voice browser library, upload that file, then refresh the portal.

No npm, Composer or SSH is needed on your hosting server. The library isn't included in this package because it could not be bundled from the official distribution in this environment.

4. Test outgoing calls first

  1. In the portal Settings, enable Allow staff to dial +1 destinations only after confirming Twilio permits this.
  2. Open Phone & Dialer and click Start phone.
  3. Allow microphone access. Wait for Ready for calls.
  4. Dial a US number you own or have permission to call, formatted +1XXXXXXXXXX.
Your Individual Compliance Profile being approved does not by itself guarantee US outbound permission. Some accounts may require Twilio Business verification before outgoing US/Canadian calls are allowed.

5. Connect incoming calls later

Preserve your working Studio Flow: Your current US-to-Kenya forwarding will continue until you intentionally switch the Twilio number's incoming handler.
  1. First verify that staff can start the browser phone and outbound calling works where permitted.
  2. Open your Twilio number +1 585 316 0597 in Voice configuration.
  3. Change the Primary method to Webhook: https://oregonproplumbing.com/phone/api/incoming.php, HTTP POST.
  4. If supported, use your existing Oregon Pro Plumbing Incoming Calls Studio Flow as the secondary/backup handler.
  5. Configure Call Status Callback as https://oregonproplumbing.com/phone/api/call-events.php, POST.
  6. Call your US number from another phone and confirm an agent's browser rings. If not answered and you've enabled a fallback number in Portal Settings, Twilio should forward to your Kenyan phone.

To revert, switch the primary Voice handler back to the original Studio Flow. International forwarding to Kenya incurs voice charges.

6. Staff accounts

As an administrator, open Team Members and create separate staff usernames and passwords. Staff click Start phone on their own computers to receive calls. You can disable inactive accounts or opt specific staff out of incoming ringing.

Use a desktop browser with HTTPS, a headset, microphone permission and stable internet. The phone does not run in the background when the browser is closed.
